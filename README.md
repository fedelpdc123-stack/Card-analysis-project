# Proyecto Analisis de Tarjetas / Cards Analysis Project

**EN:** Credit card analysis project using SQL and Power BI.  
Built on a star schema with 3 related datasets (customers, cards, transactions).  
Focus on portfolio composition, customer behavior, and risk segmentation, etc.

Análisis en SQL y Power BI de modelo estrella de 3 datasets relacionados.

## Contexto
Fecha de referencia del análisis: 01/01/2026

## Datos
- 6.146 tarjetas de credito (cards_data)
- 2.000 clientes (users_data)
- 1.048.575 transacciones (transactions_data)

## Herramientas
Power BI Desktop, DAX, Power Query, SQL

## Análisis en Power BI
1. Análisis del portfolio de tarjetas
2. Composición del portfolio
3. Vencimientos
4. Límites de crédito
5. Aperturas
6. Actualizaciones
7. Perfil financiero
8. Transacciones
9. Clientes de riesgo

## Análisis en SQL
1. Transformación de datos
2. Composición del portfolio
3. Vencimientos
4. Límites de crédito
5. Aperturas

7. Perfil financiero

## Hallazgos principales
-Más de la mitad de las tarjetas están vencidas (54%)
-Cerca de un tercio de las tarjetas se actualizaron en los últimos 10 años 
-2020 es, con diferencia, el año con más aperturas de cuentas
-El 68% de los clientes son de alto riesgo
-A mayor ingreso anual mayor gasto por transacción
